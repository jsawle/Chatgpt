# Earthquake Locator 3D

A single-file, client-side educational app built with the ArcGIS Maps SDK for JavaScript.

## Deploy to GitHub Pages

1. Rename `earthquake-locator-3d.html` to `index.html`.
2. Add it to the root of a GitHub repository.
3. In the repository, open **Settings > Pages**.
4. Choose **Deploy from a branch**, select the publishing branch and root folder, then save.

No build step or backend is required. The app loads the ArcGIS Maps SDK, basemap, and elevation service online, so it requires an internet connection.

## Included learning features

- ArcGIS 3D SceneView with World Elevation
- P- and S-wave animation
- Four synchronized seismograms
- Surface triangulation circles
- Underground focus, epicentre, and depth line
- Guided lesson sequence and teacher prompts
- Mystery-earthquake challenge with longitude, latitude, and depth estimates

## Scientific scope

This is an educational model using constant average P- and S-wave speeds. Professional earthquake location uses more stations, Earth velocity models, phase picking, and numerical error minimization.
